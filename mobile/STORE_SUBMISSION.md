## iOS App Store

### Pre-submission checklist
- [ ] Apple Developer account active ($99/year) — https://developer.apple.com
- [ ] App ID registered: com.complinow.app
- [ ] Distribution certificate + provisioning profile created in Xcode
- [ ] App icons added to `ios/Runner/Assets.xcassets/AppIcon.appiconset/`
      Required sizes: 20, 29, 40, 60, 76, 83.5, 1024pt (see Contents.json)
- [ ] Launch screen configured (`LaunchScreen.storyboard`)
- [ ] Privacy policy URL live: https://complinow.com/privacy
- [ ] Support URL live: https://complinow.com/support

### Build & submit
```bash
# In Xcode: Product → Archive → Distribute App → App Store Connect
flutter build ipa --release
```

### App Store Connect fields
- **Description**: CompliNow is a healthcare compliance management platform
  for medical clinics, urgent care centers, and multi-site health organizations.
  Conduct inspections, manage credentials, track corrective actions, and ensure
  staff policy acknowledgment — all from your mobile device.
- **Keywords**: compliance, healthcare, inspection, HIPAA, OSHA, medical, clinic,
  audit, certification, corrective action
- **Privacy Policy URL**: https://complinow.com/privacy
- **Support URL**: https://complinow.com/support

### Screenshots needed (per device)
- iPhone 6.9" (1290×2796): Dashboard, Inspection, Policies, Corrective Actions, Credentials
- iPhone 6.5" (1242×2688): same 5 screens
- iPad Pro 13" (optional but recommended)

## Google Play Store

### Pre-submission checklist
- [ ] Google Play Developer account ($25 one-time) — https://play.google.com/console
- [ ] App created in Play Console
- [ ] Keystore generated and stored securely (NOT in git):
  ```bash
  keytool -genkey -v -keystore complinow-release.jks \
    -alias complinow -keyalg RSA -keysize 2048 -validity 10000
  ```
- [ ] Set environment variables for CI/CD:
  - `KEYSTORE_PATH`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`
- [ ] App icons: 512×512 PNG for Play Store listing
- [ ] Feature graphic: 1024×500 PNG
- [ ] Privacy policy URL live: https://complinow.com/privacy

### Build & submit
```bash
flutter build appbundle --release
# Upload android/app/build/outputs/bundle/release/app-release.aab
```

### Play Console fields
- **Short description** (80 chars): Mobile compliance management for healthcare organizations
- **Full description**: [same as iOS description above]
- **Category**: Business
- **Content rating**: Everyone (complete questionnaire in Play Console)

### Data Safety (Play Console → App Content → Data Safety)
| Data | Collected | Shared | Required |
|---|---|---|---|
| Email address | Yes | No | Yes |
| Name | Yes | No | Yes |
| Photos | Yes | No | Optional |
| Precise location | Yes | No | Optional |
| App interactions | Yes | No | Yes |

## Both Stores — What You Need From a Designer

The following assets require PNG files not auto-generated by code:
1. **App icon** (1024×1024 master) — use CompliNow brand mark on navy background
2. **iOS icon set** — generate from master using https://appicon.co or Xcode
3. **Android adaptive icon** — foreground + background layers (see `mipmap-*` folders)
4. **Store screenshots** — 5 screenshots showing key screens on device frames
5. **Feature graphic** (Android) — 1024×500 banner

## CI/CD (optional but recommended)
Use **Fastlane** or **Codemagic** to automate builds and uploads.
- iOS: `fastlane deliver` + `fastlane match` for cert management
- Android: `fastlane supply` for automated AAB upload
